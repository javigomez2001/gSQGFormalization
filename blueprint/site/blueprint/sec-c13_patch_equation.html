12 Beyond the paper: derivation from the 2D patch equation

This chapter derives the graph equation from a two-dimensional weak patch system and proves its converse for the smooth unbounded graphs used in theorem 1.31. All declarations of this chapter are formalized in Lean. The scope is weak patch solutions with smooth interfaces before the corner time \(T\): no classical vector velocity on the interface and no continuation beyond \(T\) is asserted. For background on contour dynamics and the divergent tangential trace see [ HS18 , Section 3.1 ] ; their parameter equals \(2-\alpha \) in the convention used here. The rotation, density orientation and time normalization are fixed explicitly below.

We work with \(1{\lt}\alpha {\lt}2\) and with a positive kernel coefficient \(c\) until the normalization in section 12.1. This includes \(\alpha =p+1\in (7/4,2)\) in the application. The space \(E=\mathbb {R}^2\) has its Euclidean norm and Lebesgue measure. In Lean, use EuclideanSpace R (Fin 2) and explicit volume-preserving coordinate maps; the default norm of a product of two real normed spaces is not the Euclidean radius. Write \(J(x_1,x_2)=(-x_2,x_1)\), so \(\nabla ^\perp =J\nabla \). Spatial and spacetime test functions are smooth and compactly supported in their indicated open domains. Constants in quantitative statements are chosen before the variables in which uniformity is asserted.

Let \(E=\mathbb {R}^2\) with the Euclidean norm, and write \((x,y)\in E\) for the point with coordinates \(x,y\). For a vector field \(Q:E\to E\) put \(\operatorname {div}Q=\partial _1Q_1+\partial _2Q_2\). For \(z\ne 0\) set

\[ P_{\alpha ,c}(z)=c|z|^{-\alpha },\qquad K_{\alpha ,c}(z)=\alpha c\, Jz\, |z|^{-\alpha -2}=-J\nabla P_{\alpha ,c}(z), \]

and set both kernels to zero at the single point zero. For a vector test function \(\Phi :E\to E\) define

\[ B^*_{\alpha ,c}\Phi (Y)=\int _E K_{\alpha ,c}(z)\cdot (\Phi (Y+z)-\Phi (Y))\, dz. \]

For a bounded measurable real density \(\theta \) define

\[ V_{\alpha ,c}[\theta ](X)=\int _E [P_{\alpha ,c}(X-Y)-\mathbf1_{|Y|{\gt}1}P_{\alpha ,c}(-Y)]\theta (Y)\, dY. \]

These are total formulas; the next lemmas establish their analytic meanings. The unsubtracted integral \(P*\theta \) is not asserted to converge for an infinite patch.

Lemma 12.3 Euclidean coordinates and radial majorants
✓
#

Uses

  • Definition 12.1

Lean declarations

  • GSQG.c13_radial_majorants

Coordinate identification \(E\leftrightarrow \mathbb {R}\times \mathbb {R}\) preserves Lebesgue measure, and \(|z|^2=z_1^2+z_2^2\). For \(r{\gt}0\),

\[ \int _{|z|{\lt}r}|z|^{-\alpha }dz=\frac{2\pi }{2-\alpha }r^{2-\alpha },\qquad \int _{|z|{\gt}r}|z|^{-\alpha -1}dz=\frac{2\pi }{\alpha -1}r^{1-\alpha }. \]

The displayed nonnegative integrands are integrable on their respective domains. Consequently there is \(C_{\alpha ,c}{\gt}0\) such that for every \(\xi \in E\),

\[ \int _E|K_{\alpha ,c}(z)|\, |e^{-iz\cdot \xi }-1|dz \le C_{\alpha ,c}|\xi |^{\alpha -1}, \]

with the integral zero when \(\xi =0\).

Proof ▶

Use the volume-preserving Euclidean-to-coordinate map and radial integration in dimension two. For the last bound split at \(r=|\xi |^{-1}\) and use \(|e^{-is}-1|\le \min (|s|,2)\). The cases \(\alpha {\gt}1\) and \(\alpha {\lt}2\) control different ends of the integral.

Lemma 12.4 \(L^1\) translation estimate for test fields
✓
#

Lean declarations

  • GSQG.c13_test_translation

For every vector test function \(\Phi :E\to E\) and every \(z\in E\),

\[ \int _E|\Phi (Y+z)-\Phi (Y)|dY \le \min \left(|z|\int _E\| D\Phi (Y)\| dY,\ 2\int _E|\Phi (Y)|dY\right). \]

All the displayed integrals are finite.

Proof ▶

Apply segment FTC to \(\Phi (Y+tz)\), integrate its norm, and use Fubini and translation invariance. The second bound is the triangle inequality. This is a finite-dimensional test-function lemma.

Lemma 12.5 Absolute adjoint pairing
✓
#

Uses

  • Lemma 12.3
  • Lemma 12.4

Lean declarations

  • GSQG.c13_adjoint_integrable

For every vector test \(\Phi \), the function \((Y,z)\mapsto K_{\alpha ,c}(z)\cdot (\Phi (Y+z)-\Phi (Y))\) is absolutely integrable on \(E\times E\). The inner integral defining \(B^*\Phi (Y)\) converges absolutely for every \(Y\), and

\[ \| B^*\Phi \| _{L^1(E)}\le C_{\alpha ,c} (\| \Phi \| _{L^1(E)}+\| D\Phi \| _{L^1(E)}). \]

Thus \(\int \theta B^*\Phi \) is absolutely convergent for every bounded measurable \(\theta \).

Proof ▶

Use Tonelli for the norm majorant and split \(|z|\le 1\) from its complement. Pointwise convergence uses the bounded derivative of the test field near zero and its bounded values at infinity.

Lemma 12.6 Test potential and adjoint divergence identity
✓
#

Uses

  • Definition 12.1
  • Lemma 12.3
  • Lemma 12.5

Lean declarations

  • GSQG.c13_test_potential

For a vector test \(\Phi \), let \(A_\Phi (Y)=\int _E P_{\alpha ,c}(X-Y)\Phi (X)dX\). This integral is absolutely convergent, \(A_\Phi \) is \(C^1\), and

\[ B^*\Phi =-\operatorname {div}(J A_\Phi ). \]

If \(\operatorname {supp}\Phi \subset \{ |X|\le L\} \), then for \(|Y|{\gt}2L+1\), \(|A_\Phi (Y)|\le C_{\alpha ,c}|Y|^{-\alpha }\| \Phi \| _1\). In particular \(B^*(\nabla \zeta )=0\) for every scalar test \(\zeta \).

Proof ▶

Differentiate the compact test factor after shifting variables. Integration by parts in the locally integrable potential kernel gives the adjoint identity; retain the cancellation at zero. For a gradient test, the scalar curl is zero by equality of mixed derivatives. Lean route: \(A_\Phi \) is the convolution \(P*\Phi \) (\(P\) even), differentiated on the compact test factor; the adjoint identity \(B^*\Phi (Y)=\int P(z)\operatorname {curl}\Phi (Y+z)dz\) is proved for the regularized kernel \(P_\delta =c(|z|^2+\delta ^2)^{-\alpha /2}\) by whole-space integration by parts and oddness of \(K_\delta \), then \(\delta \to 0\) by dominated convergence, keeping the cancellation \(\Phi (Y+z)-\Phi (Y)\) until the limit.

Lemma 12.7 Absolute convergence of the renormalized potential
✓
#

Uses

  • Definition 12.1
  • Lemma 12.3

Lean declarations

  • GSQG.c13_potential_convergence

For every \(R\ge 1\) there is \(C_{\alpha ,c,R}{\gt}0\) such that for every bounded measurable \(\theta \) with \(|\theta |\le M\), \(M\ge 0\), and every \(|X|\le R\),

\[ \int _E|P(X-Y)-\mathbf1_{|Y|{\gt}1}P(-Y)|\, |\theta (Y)|dY\le C_{\alpha ,c,R}M. \]

The integral defining \(V[\theta ]\) is therefore absolutely convergent at every \(X\), measurable and locally bounded. Changing the subtraction radius to another positive radius changes it by a finite constant independent of \(X\).

Proof ▶

On \(|Y|{\gt}2R+2\), use the mean-value estimate \(|P(X-Y)-P(-Y)|\le C_{\alpha ,c}R|Y|^{-\alpha -1}\). In the remaining bounded region integrate the translated singular kernel using its radial integral. Measurability follows from parameter integration. The difference of two subtraction choices is an integral over a bounded annulus and contains no \(X\).

Lemma 12.8 Renormalized potential and its distributional gradient
✓
#

Uses

  • Lemma 12.7
  • Lemma 12.5

Lean declarations

  • GSQG.c13_renormalized_potential_properties

For every bounded measurable \(\theta \), the defining integral for \(V_{\alpha ,c}[\theta ](X)\) converges absolutely for every \(X\) and defines a locally bounded measurable function. For every vector test \(\Phi \),

\[ \int _E\theta B^*\Phi =-\int _E V_{\alpha ,c}[\theta ]\, \operatorname {div}(J\Phi ). \]

Both sides converge absolutely. This is \(B_{\alpha ,c}\theta =-J\nabla V_{\alpha ,c}[\theta ]\) in distributions. Replacing the subtraction radius \(1\) by another positive radius changes \(V\) by a finite constant independent of \(X\) and leaves the velocity unchanged.

Proof ▶

For \(|Y|{\gt}2|X|+2\), the subtracted kernel is bounded by \(C_{\alpha ,c}|X||Y|^{-\alpha -1}\). Near \(Y=X\) use local integrability of \(|X-Y|^{-\alpha }\). Establish local bounds by integrating the singular kernel, not by taking a pointwise supremum over its moving pole. Integrate by parts in the kernel with a small-radius cutoff; its error is \(O(r^{2-\alpha })\). Keep the subtraction until Fubini is justified. Its contribution against \(\operatorname {div}(J\Phi )\) then vanishes because the integral of a compactly supported divergence is zero.

Lemma 12.9 Gamma layer representation of the singular kernel

For \(z\ne 0\),

\[ |z|^{-\alpha }=\frac1{\Gamma (\alpha /2)}\int _0^\infty s^{\alpha /2-1}e^{-s|z|^2}ds,\qquad K_{\alpha ,c}(z)=\frac{2c}{\Gamma (\alpha /2)}Jz\int _0^\infty s^{\alpha /2}e^{-s|z|^2}ds. \]

Lemma 12.10 Two-dimensional Gaussian transform and first moment
✓
#

  • GSQG.c13_gaussian_first_moment

For every \(s{\gt}0\) and \(\xi \in E\), the following integrals converge absolutely:

\[ \int _Ee^{-s|z|^2-i z\cdot \xi }dz=\frac\pi s e^{-|\xi |^2/(4s)},\qquad \int _E z e^{-s|z|^2-i z\cdot \xi }dz =-\frac{i\pi }{2s^2}\xi e^{-|\xi |^2/(4s)},\qquad \int _E z e^{-s|z|^2}dz=0. \]

Proof ▶

Apply the inner-product-space Gaussian Fourier integral in dimension two with phase coefficient \(-i\), or coordinate Fubini and the one-dimensional formula. Definition 12.14 Admissible graphs, patches and canonical representatives
✓

Let \(I\) be a nonempty open time interval. A graph \(F:\mathbb {R}\times I\to \mathbb {R}\) is admissible if it is jointly smooth on \(\mathbb {R}\times I\) (no smoothness is required at the endpoints of \(I\) or outside \(\mathbb {R}\times I\)) and for every compact interval \(J_0\subset I\) there is \(M_{J_0}\ge 0\) with \(|F_x(x,t)|\le M_{J_0}\) for all \(x\in \mathbb {R},t\in J_0\). No global bound on \(F\), \(F_{xx}\) or time derivatives at spatial infinity is assumed. Put \(\gamma _t(s)=(s,F(s,t))\), \(\tau _t(s)=(1,F_x(s,t))\), \(\Omega _t=\{ (x,y):y{\lt}F(x,t)\} \), and \(\theta _F=\mathbf1_{\Omega _t}\). Define, for \(X\notin \Gamma _t=\gamma _t(\mathbb {R})\),

\[ U_{\alpha ,c}[F](X,t)=-c\int _\mathbb {R}\tau _t(s)|X-\gamma _t(s)|^{-\alpha }ds, \]

and give \(U\) value zero on \(\Gamma _t\). This candidate boundary representation is not assumed to satisfy the two-dimensional velocity law; that is proved in section 12.4. Define separately

\[ W_{\alpha ,c}[F](x,t)=c\int _\mathbb {R}[F_x(x,t)-F_x(s,t)]|\gamma _t(x)-\gamma _t(s)|^{-\alpha }ds. \]

The graph normal is \((-F_x,1)/\sqrt{1+F_x^2}\); \(W\) is its normal velocity multiplied by \(\sqrt{1+F_x^2}\). It is not the value of the arbitrarily extended vector field on the graph.

Lemma 12.15 Measurability, null graphs and a distance bound
✓
#

Uses

Lean declarations

Each patch is measurable, each graph has two-dimensional measure zero, and the spacetime graph has three-dimensional measure zero. For a fixed-time slope bound \(|F_x|\le M\), let \(h=s-x\) and \(\delta =y-F(x,t)\). Then

The same constants work on a compact time interval with its common slope bound.

Proof ▶

Openness of the subgraph follows from continuity; Fubini makes each vertical graph section a null singleton. Use \(|F(s,t)-F(x,t)|\le M|h|\) and the squared triangle inequality.

Lemma 12.16 Finite graph-domain flux formula
✓
#

Uses

  • Definition 12.1

Lean declarations

  • GSQG.c13_finite_graph_flux

Let \(R{\gt}0\), \(F\in C^1(\mathbb {R})\), \(H{\gt}0\) with \(-H{\lt}F(s)\) for \(|s|\le R\), and \(Q:E\to E\) be \(C^1\) on a neighborhood of the closed domain \(D=\{ (s,y):|s|{\lt}R,-H{\lt}y{\lt}F(s)\} \). Then

\[ \begin{split} \int _D\operatorname {div}Q ={}& \int _{-R}^{R}(Q_2-F’Q_1)(s,F(s))ds-\int _{-R}^{R}Q_2(s,-H)ds\\ & +\int _{-H}^{F(R)}Q_1(R,y)dy-\int _{-H}^{F(-R)}Q_1(-R,y)dy . \end{split} \]

Every integral is absolutely convergent.

Proof ▶

Coordinate Fubini and vertical FTC give the \(Q_2\) terms. Differentiate \(s\mapsto \int _{-H}^{F(s)}Q_1(s,y)dy\), then use one-dimensional FTC. This is the graph-specific substitute for a general Gauss theorem. Lean route: for the \(x\)-derivative term substitute \(y=(F(s)+H)\tau -H\), which maps the domain to the rectangle \([-R,R]\times [0,1]\), then use Fubini there and FTC in \(s\) and in \(\tau \).

Lemma 12.17 Flux formula for an unbounded subgraph and a compact test field
✓

For a \(C^1\) graph with bounded slope and a compactly supported \(C^1\) vector field \(Q\),

\[ \int _{y{\lt}F(x)}\operatorname {div}Q(X)dX =\int _\mathbb {R}(Q_2-F'Q_1)(x,F(x))dx, \]

12.6 Transport and equivalence with the front equation

Definition 12.27 Weak patch system with coefficient \(c\)
✓
#

Uses

  • Definition 12.1
  • Definition 12.14

Lean declarations

  • GSQG.c13_scalar_test
  • GSQG.c13_vector_test
  • GSQG.c13_velocity_law
  • GSQG.c13_weak_patch_system

A scalar (respectively vector) spacetime test on \(E\times I\) is a smooth compactly supported function \(E\times \mathbb {R}\to \mathbb {R}\) (respectively \(E\times \mathbb {R}\to E\)) whose support lies in \(E\times I\). A bounded measurable density \(\theta :E\times I\to \mathbb {R}\) and a measurable \(u\in L^1_{\rm loc}(E\times I;E)\) obey the coefficient-\(c\) velocity law if, for every vector spacetime test \(\Phi \),

\[ \int _I\! \int _E u(X,t)\cdot \Phi (X,t)dXdt =\int _I\! \int _E\theta (Y,t)B^*_{\alpha ,c}(\Phi (\cdot ,t))(Y)dYdt. \]

They solve the weak patch system if also, for every scalar spacetime test \(\zeta \),

\[ \int _I\! \int _E\theta (X,t) [\partial _t\zeta (X,t)+u(X,t)\cdot \nabla _X\zeta (X,t)]dXdt=0. \]

All pairings must be absolutely integrable. For \(\theta =\theta _F\) boundedness is automatic. With \(c=c_{\rm std}\) this is the canonical gSQG operator, as identified in section 12.1. The product \(\theta u\) is formed only after obtaining the locally integrable velocity representative.

Lemma 12.33 Local time continuity and the initial-value formulation
